```text
java-practice/

```

## 🛠️ Technologies Used

- **Language:** Java
- **JDK:** Java Development Kit
- **Editor:** Visual Studio Code

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Rohan01002/java-practice.git
```

### 2. Navigate to the project folder

```bash
cd java-practice
```

### 3. Compile the Java program

```bash
javac part01.java
```

### 4. Run the program

```bash
java part01
```
